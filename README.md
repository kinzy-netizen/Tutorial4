\# Tutorial 4 – Git and GitHub Collaboration



\## Purpose

The purpose of this repository is to demonstrate how to create and manage a Git repository, work with branches, add files, commit changes, and collaborate using GitHub.



\## Steps Followed

1\. Installed and configured Git.

2\. Created a local Git repository.

3\. Connected the local repository to GitHub.

4\. Added a collaborator.

5\. Created a new branch.

6\. Added and committed a new file.

7\. Created a pull request for review.

8\. Merged the approved changes into the main branch.
